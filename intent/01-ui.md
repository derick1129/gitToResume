# UI Specification

The entire application must closely match the supplied reference design.

This is not inspiration.

It is the visual target.

The final interface should feel almost identical in spacing, typography, sizing, hierarchy, and minimalism.

---

# Overall Style

Extremely minimal.

Almost monochrome.

Very large whitespace.

Everything centered.

No gradients.

No bright colors.

No glassmorphism.

No cards unless necessary.

No decorative illustrations.

The design should feel like:

- Linear
- Vercel
- Raycast
- Notion
- Apple

---

# Color Palette

Background

Pure white (#FFFFFF)

Primary Text

Near black (#111111)

Secondary Text

Gray (#6B7280)

Borders

Very light gray (#EAEAEA)

Buttons

Black background

White text

Hover:

Slightly lighter black

Nothing flashy.

---

# Typography

Large bold hero heading.

Approximately 72–96px on desktop.

Heavy font weight.

Very tight line height.

Centered.

Subheading:

16–20px

Medium gray

Maximum width around 650px.

Everything centered.

Small labels should use uppercase with increased letter spacing.

---

# Navigation

Minimal top navigation.

Logo on left.

Few links on right.

Simple text links.

Primary CTA outlined.

Large horizontal spacing.

Very thin bottom border.

No shadows.

---

# Hero Section

Contains:

Small badge

↓

Large heading

↓

Short description

↓

Username input

↓

Generate button

↓

Small technology labels

↓

Optional secondary button

Everything vertically centered.

Large spacing between elements.

---

# Hero Badge

Rounded pill.

Thin border.

Uppercase text.

Very small font.

Wide letter spacing.

Centered.

OUTPUT: VECTOR_PDF | 100% CLIENT SIDE

---

# Hero Heading

Three-line layout.

Very bold.

Very large.

Centered.

This should be the strongest visual element on the page.

---

# Hero Description

Centered.

Gray.

Readable.

Approximately two lines.

Do not exceed 650px width.

---

# Username Input

Single horizontal component.

Rounded container.

Thin border.

Large padding.

Inside:

GitHub prefix

↓

Username input

↓

Generate button

The Generate button sits inside the container on the right.

The button should be black with white text.

---

---

# Secondary Button

Small outlined button.

Rounded.

Contains icon.

Minimal.

Centered.

---

# Layout

Maximum width approximately 1200px.

Hero content width approximately 900px.

Generous vertical spacing.

Everything centered.

---

# Spacing

Whitespace is critical.

Avoid filling the page.

Every section should breathe.

Content density should remain low.

---

# Components

Buttons

Rounded.

Minimal.

Subtle hover.

No glow.

Inputs

Rounded.

Thin border.

No heavy focus rings.

Icons

Simple outline icons.

Small.

Consistent stroke width.

---

# Animations

Very subtle.

Fade in.

Small upward motion.

Button hover:

Scale 1.01

Input focus:

Smooth border transition.

Nothing should bounce.

No exaggerated motion.

---

# Responsive

Desktop first.

Tablet:

Maintain centered layout.

Mobile:

Stack input above button.

Typography scales smoothly.

Padding remains generous.

---

# Visual Rules

Never use:

- gradients
- colorful backgrounds
- neumorphism
- heavy shadows
- glass effects
- oversized icons
- noisy illustrations

Always prioritize:

- whitespace
- typography
- alignment
- hierarchy
- consistency

The final UI should look indistinguishable from the provided reference image while remaining fully responsive and accessible.
